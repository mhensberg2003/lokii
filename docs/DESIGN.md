# Lokii design references

Direction: **calm dark**. A near-black neutral shell. Show artwork gives the color. One soft accent for focus, progress and the primary button. Few, large elements with wide gutters.

Mood board: https://claude.ai/artifact/GdzqTWZ3sVqz4WTn3TmR86

## Reference per screen

| Screen | Reference | Take |
|---|---|---|
| Home hero | [Netflix](https://mobbin.com/screens/651b69e1-68af-49a9-9b27-687559314100) | Full-bleed key art, large title, short synopsis, Play + More info. The first row starts above the fold. |
| Show page | [Disney+](https://mobbin.com/screens/cf7c3e99-7164-4679-ab4a-a55233ea8e2e) | Key art fades into the page. Tabs (Episodes, Related, Details). Season picker from the Franchise. Episode grid: thumbnail, number + title, 2-line synopsis, runtime, Watch Progress bar. |

| Browse | [Paramount+](https://mobbin.com/screens/8a367dbd-17e3-42a1-ab38-14775a8c72b7) | Genre tab strip on top. Each tab shows curated poster rows for that genre: Airing now, Most popular, Top rated, This season. Not a plain genre list. |
| App shell | Mood board notes | Persistent left sidebar: Home, Browse, Library, Downloads, Settings. Search in the top bar, opened with Cmd/Ctrl+K. Content scrolls, the shell stays. |
| Downloads | [Grok](https://mobbin.com/screens/4c0bbc8f-c16b-4980-ad57-0c10e2406aab) | Floating activity panel, bottom-right, one line per Stream with a status icon (preparing, buffering, 42%, ready). A full Downloads page shows speed, peers and size. |
| Settings | [Cursor](https://mobbin.com/screens/e6afde3a-ca5e-413f-8460-015397bf1d00) | Left settings nav. Grouped white-space rows, each with a name, one-line description and one action (Connect, Manage). A masked TorBox API key row. |

## Rules

- No carousels with dots. No more than 4 rows on Home.
- Torrent details (peers, speed, seeders) appear only on the Downloads page and in the Change release list.
- The UI stays grey. Color comes from artwork only, plus the one accent.
